## Palette.kt

1. `internal data class Command(val label: String, val keys: String?, val id: String)`

2. `internal val COMMANDS: List<Command>` with exactly these, in this order, ids exact:

compose "Write a new message" C | reply "Reply" R | reply-all "Reply to everyone" A |
forward "Forward" F | archive "Archive" E | trash "Move to trash" Del |
junk "Mark as spam" null | star "Star or unstar" S | read "Mark as read" null |
tag "Add a tag" null | source "View source" null | save-eml "Save as .eml" null |
search "Search" / | refresh "Check for mail now" F5 | next "Next message" J |
previous "Previous message" K | go-inbox "Go to inbox" null |
go-unified "Go to all inboxes" null | go-archive "Go to archive" null |
go-sent "Go to sent" null | go-drafts "Go to drafts" null | settings "Settings" Ctrl+, |
shortcuts "Keyboard shortcuts" ?

3. `internal fun matches(query: String, commands: List<Command> = COMMANDS): List<Command>`

- Blank query returns the whole list unchanged.
- Case insensitive.
- Subsequence match: every character of the query appears in the label in order, not
  necessarily adjacent. "rpl" matches "Reply". "gtarch" matches "Go to archive".
- Sorted best first: label starts with the query, then label contains the query as a
  run, then plain subsequence. Inside a tier keep the original COMMANDS order. Never
  sort alphabetically.
- No match returns an empty list.
- Pure function, no new dependency.

4. `@Composable internal fun CommandPalette(onClose: () -> Unit, onRun: (Command) -> Unit)`

- Dimmed scrim over the window, closes on click, no ripple (use
  `clickable(interactionSource = remember { MutableInteractionSource() }, indication = null, onClick = onClose)`).
- Card near the top centre, 520.dp wide, MaterialTheme.shapes.medium, surface colour.
- A BasicTextField at the top, hint "Type a command" when empty, focused at once with
  a FocusRequester in LaunchedEffect(Unit).
- At most 8 matching rows: label left, keys right in colorScheme.outline. Highlighted
  row has a surfaceVariant background.
- Modifier.onPreviewKeyEvent on the field: Down and Up move the highlight and wrap,
  Enter runs the highlighted command then closes, Escape closes, everything else false.
- "Nothing matches that." in bodySmall and outline when nothing matches.
- Highlight resets to 0 when the query changes or it would point past the end.

## House style, matters more than speed

Comments say WHY never WHAT, and never restate the line under them. No em dashes, no en
dashes, no ellipsis characters anywhere including comments. Plain English, sentence case,
no exclamation marks in anything a user sees. 4-space indent, 110 columns, trailing commas
in multi-line argument lists. internal not public. No new dependencies.
